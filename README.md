# auto_printer

여러 개의 한글(HWP) 문서를 **문서마다 정해진 부수만큼** 한 번에 인쇄하는 도구입니다.
회차마다 폴더를 복사해 내용만 고치고 다시 출력하는 청구 서류 작업처럼, 문서별 출력 부수가 제각각인 반복 작업을 위해 만들었습니다.

- 회차 폴더를 지정하면 그 안의 모든 hwp 파일 목록을 엑셀로 만들어 줍니다.
- 엑셀에서 부수만 고치면, 목록대로 부수만큼 인쇄합니다.
- 인쇄 명령마다 프린터 대기열 접수를 확인하므로, 출력이 누락되면 '실패'로 기록됩니다.

> **실행 환경:** Windows 10/11, 한/글(Hancom Office) 설치 필수, Python 3
> (확인 환경: Windows 11, 한/글 2018 10.0.0.13015, Python 3.14, Brother MFC-T800W)

---

## 폴더 구성

```
auto_printer/
├─ 0.setup_security_module.py    한글 보안모듈 설치 (최초 1회)
├─ 1.hwp_list_maker.py           회차 폴더의 hwp 파일 목록(엑셀) 생성
├─ 2.hwp_print.py                목록대로 부수만큼 인쇄
├─ 1.hwp_list_maker_명령어.txt    자주 쓰는 실행 명령 메모 (복사해서 붙여넣기용)
├─ 2.hwp_print_명령어.txt
├─ requirements.txt              필요한 파이썬 라이브러리 목록
└─ print_list/                   생성된 목록과 인쇄 기록이 저장되는 폴더
```

`print_list/` 안의 파일(목록, 로그)에는 기관명과 PC 경로가 들어 있어 git에 올라가지 않도록 `.gitignore`에서 제외했습니다.

## 1. 최초 1회 준비

**① Python 설치**
[python.org](https://www.python.org/downloads/)에서 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.

**② 라이브러리 설치** — 이 폴더에서 명령 프롬프트(cmd)를 열고:

```
pip install -r requirements.txt
```

| 라이브러리 | 용도 |
|---|---|
| pywin32 | 한글 자동화 제어, 프린터 대기열 확인 |
| openpyxl | 엑셀 목록 만들기·읽기 |

**③ 한글 보안모듈 설치** (권장)

```
python 0.setup_security_module.py
```

자동화로 문서를 열 때마다 뜨는 "위 파일에 접근하려는 시도가 있습니다" 승인 창을 없애 줍니다.
한컴 공식 GitHub에서 보안모듈을 내려받아 `%APPDATA%\hwp_print_tool`에 설치하고, 현재 사용자 레지스트리(`HKCU\SOFTWARE\HNC\HwpAutomation\Modules`)에 등록합니다. 관리자 권한은 필요 없습니다.
자동 다운로드가 안 되면 화면 안내대로 zip 파일을 직접 받아 이 폴더에 두고 다시 실행하세요.

## 2. 매 회차 사용 순서

명령은 모두 **이 폴더에서 연 명령 프롬프트**에서 실행합니다.
매번 경로를 치기 번거로우면 `명령어.txt` 파일을 열어 회차명만 바꾼 뒤 복사해 붙여넣으세요.

### 1단계. 회차 폴더 준비
이전 회차 폴더를 복사해 새 회차 폴더를 만들고, 문서 내용을 수정합니다.

### 2단계. 인쇄 목록 만들기

```
python 1.hwp_list_maker.py "C:\...\2026년 10월 청구리스트"
```

지정한 폴더 아래 **모든 하위 폴더**의 hwp 파일을 찾아 `print_list\print_list_2026년 10월 청구리스트.xlsx`를 만듭니다. 부수는 전부 1로 채워집니다.
같은 이름의 목록이 이미 있으면 덮어쓰지 않고 이름 뒤에 날짜시간을 붙여 새로 저장합니다. 부수를 고쳐 둔 목록이 실수로 지워지지 않게 하기 위해서입니다.

### 3단계. 부수 수정
만들어진 엑셀 파일을 열어 **'부수' 열만** 고치고 **저장(Ctrl+S)** 합니다.

- 인쇄하지 않을 문서는 **0**을 입력합니다.
- CSV로 따로 저장할 필요는 없습니다. 엑셀 파일을 그대로 쓰면 됩니다. CSV 목록도 지원합니다.
- 저장하지 않은 수정 내용은 반영되지 않습니다.

### 4단계. 미리보기 (실제 인쇄 없음)

```
python 2.hwp_print.py "print_list\print_list_2026년 10월 청구리스트.xlsx" --dry-run
```

어떤 파일이 몇 부씩 인쇄될지 보여 줍니다. **총 파일 수와 부수가 맞는지 꼭 확인하세요.**
"존재하지 않는 파일" 경고가 뜨면 회차 폴더명을 안 바꿨거나 파일명에 오타가 있는 경우입니다.

### 5단계. 인쇄

```
python 2.hwp_print.py "print_list\print_list_2026년 10월 청구리스트.xlsx"
```

목록을 보여 준 뒤 `(y/n)` 확인을 받고 인쇄를 시작합니다. 확인 없이 바로 시작하려면 `--yes`를 붙입니다.

### 6단계. 결과 확인
인쇄가 끝나면 `print_list` 폴더에 결과 기록이 남습니다.

| 파일 | 내용 |
|---|---|
| `print_log_날짜시간.txt` | 문서별 성공/실패와 총 출력 부수 (항상 생성) |
| `print_debug_날짜시간.log` | 실패 원인 상세 기록 (실패가 있을 때만 생성) |

**'실패' 항목이 있으면** 엑셀 목록에서 성공한 행의 부수를 0으로 바꿔 저장한 뒤 다시 실행하면, 실패한 문서만 다시 인쇄됩니다.

## 3. 목록 파일 형식

`1.hwp_list_maker.py`가 만드는 형식입니다. 직접 만들어도 됩니다.

| 1차경로 | 2차경로 | 파일명 | 부수 |
|---|---|---|---|
| C:\\...\\2026년 10월 청구리스트 | C01_03_2_합천군청 재무과 | 2. 청구서.hwp | 1 |
| C:\\...\\2026년 10월 청구리스트 | C01_01_2_창녕군청\\2. 수도과 | 3. 유지보수완료계 2부.hwp | 2 |

- **첫 행은 항상 제목 줄**로 보고 건너뜁니다. 열 이름은 자유입니다.
- **마지막 열이 부수**이고, 그 앞의 열들은 순서대로 `\`로 이어 붙여 전체 경로가 됩니다. 경로 조각 열의 개수는 몇 개든 괜찮고, 빈 칸은 무시합니다.
- 엑셀(.xlsx)은 첫 번째 시트를 읽습니다. CSV는 쉼표/탭 구분과 인코딩(UTF-8, CP949 등)을 자동으로 인식합니다.

## 4. 인쇄 방식

인쇄는 두 가지 경로가 있으며, 기본은 **자동화 인쇄를 먼저 시도하고 실패하면 셸 인쇄로 전환**합니다.

| | 자동화(COM) 인쇄 — 1순위 | 셸 인쇄 — 우회 경로 |
|---|---|---|
| 방식 | 파이썬이 한글 본체를 직접 제어해 인쇄 | 탐색기에서 우클릭 → 인쇄와 같은 방식 (한글 인쇄 관리자 `HwpPrnMng.exe`가 출력) |
| 프린터 지정 (`--printer`) | 가능 | 불가 (항상 Windows 기본 프린터) |
| 한글 창 | 숨긴 채 진행 (`--visible`로 표시 가능) | 한글 인쇄 관리자가 처리 |
| 인쇄 간격 | 대기열 접수 확인 후 `--delay`(기본 1.5초) | 대기열 접수 확인 + 최소 **6초** |

- 자동화 인쇄가 한 번 실패하면 **실패한 문서부터 끝까지 셸 인쇄로 진행**합니다. 실패한 문서도 셸 인쇄로 다시 출력하므로 누락되지 않습니다.
- 셸 인쇄로 2부 이상 출력할 때는 임시 복사본을 만들어 부수만큼 따로 인쇄합니다. 한글이 같은 문서의 연속 인쇄 명령을 무시하기 때문이며, 복사본은 자동으로 정리됩니다.
- 처음부터 셸 인쇄만 쓰려면 `--shell-only`를 붙입니다.

### 알려진 문제: 한/글 2018 + Brother MFC-T800W

이 조합에서는 **자동화 인쇄 실행 순간 한글이 비정상 종료**됩니다. 그래서 이 PC에서는 매번 첫 문서에서 자동화가 실패하고 셸 인쇄로 넘어갑니다. 출력에는 문제가 없지만, 실행할 때마다 `[재시도]` 메시지와 `print_debug` 로그가 생깁니다.

| 확인한 내용 | 결과 |
|---|---|
| 오류 위치 | `hwp.exe`가 `MSVCR120.dll`에서 강제 종료 (예외 코드 0xc0000409) |
| 가상 PDF 프린터로 자동화 인쇄 | 정상 |
| Brother로 자동화 인쇄 (창 숨김 / 창 표시) | 둘 다 종료 |
| 프린터 드라이버 재설치, VC++ 2013 런타임 최신화 | 해결 안 됨 |

이 과정을 건너뛰려면 `--shell-only`로 실행하세요. 다른 프린터나 다른 한글 버전에서는 자동화 인쇄가 정상 동작할 수 있어 1순위로 남겨 두었습니다.

## 5. 옵션

### 2.hwp_print.py

| 옵션 | 설명 |
|---|---|
| `--dry-run` | 실제 인쇄 없이 목록과 부수만 확인 |
| `--yes` | `(y/n)` 확인 없이 바로 인쇄 |
| `--shell-only` | 자동화 인쇄를 건너뛰고 처음부터 셸 인쇄만 사용 |
| `--printer 이름` | 기본 프린터가 아닌 프린터로 인쇄 (자동화 인쇄에서만 적용) |
| `--visible` | 자동화 인쇄 중 한글 창을 화면에 표시 (문제 확인용) |
| `--delay 초` | 인쇄 명령 후 대기 시간 (기본 1.5초, 셸 인쇄는 최소 6초) |
| `--spool-timeout 초` | 프린터 대기열 접수를 기다리는 최대 시간 (기본 30초). 큰 문서가 시간 초과로 실패하면 늘리세요 |
| `--csv 경로` | (폴더 지정 방식 전용) 부수 목록 CSV 직접 지정 |

### 1.hwp_list_maker.py

| 옵션 | 설명 |
|---|---|
| `--output 경로.xlsx` | 목록 저장 위치와 이름을 직접 지정 |
| `--copies N` | 부수 기본값 (기본 1) |

### 코드 상단 설정값

| 파일 | 설정 | 기본값 | 의미 |
|---|---|---|---|
| 1.hwp_list_maker.py | `OUTPUT_DIR` | 이 폴더의 `print_list` | 목록 저장 폴더 |
| 2.hwp_print.py | `SHELL_PRINT_GAP` | 6.0 | 셸 인쇄 명령 사이 최소 간격(초) |
| 2.hwp_print.py | `DEFAULT_COPIES` | 1 | (폴더 지정 방식) 목록에 없는 파일의 부수 |
| 2.hwp_print.py | `MANUAL_COPIES` | 비어 있음 | (폴더 지정 방식) 코드에 직접 적는 파일별 부수 |

### 참고: 폴더 지정 방식

목록 파일 대신 폴더를 지정할 수도 있습니다.

```
python 2.hwp_print.py "C:\...\제출서류폴더"
```

그 폴더 **바로 안**의 hwp 파일만 대상으로 하고(하위 폴더 제외), 부수는 폴더 안 `부수목록.csv`(파일명, 부수 2열) → `MANUAL_COPIES` → `DEFAULT_COPIES` 순서로 정합니다. 회차형 작업에는 목록 파일 방식을 권장합니다.

## 6. 문제 해결

**`'python'은(는) 내부 또는 외부 명령...이 아닙니다`**
Python 설치 시 PATH 추가를 하지 않은 경우입니다. Python을 다시 설치하면서 "Add python.exe to PATH"를 체크하세요.

**`No module named ...` 오류**
`pip install -r requirements.txt`를 실행하세요.

**보안 승인 창("위 파일에 접근하려는 시도...")이 계속 뜸**
`python 0.setup_security_module.py`를 실행하세요. 그래도 뜨면 한글을 완전히 종료한 뒤 다시 시도하세요.

**`[재시도] 자동화 인쇄 실패(... 원격 프로시저를 호출하지 못했습니다 ...)`**
자동화 인쇄 중 한글이 종료된 것입니다. 위 [알려진 문제](#알려진-문제-한글-2018--brother-mfc-t800w) 참고. 출력은 셸 인쇄로 정상 진행됩니다.

**`... 프린터 대기열에 나타나지 않았습니다`로 실패**
프린터 전원·용지·연결 상태와 화면에 한글 대화 상자가 떠 있지 않은지 확인한 뒤, 실패 항목만 다시 인쇄하세요. 아주 큰 문서라면 `--spool-timeout 60`처럼 시간을 늘려 보세요.

**`--printer`로 지정했는데 기본 프린터로 출력됨**
셸 인쇄로 전환된 문서는 항상 Windows 기본 프린터로 출력됩니다. 다른 프린터로 내보내려면 Windows 설정에서 기본 프린터를 바꾸세요.

**목록에 있는 파일이 미리보기에 안 보임**
목록 파일 첫 행이 제목 줄인지, 부수가 0이거나 비어 있지 않은지, 엑셀에서 수정 후 저장했는지 확인하세요.

**`pywin32` 관련 오류 / `AttributeError`**
win32com 캐시 문제인 경우가 많습니다. `%LOCALAPPDATA%\Temp\gen_py` 폴더를 삭제한 뒤 다시 실행하세요.
